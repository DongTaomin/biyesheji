## 三、API 接口清单表

| 接口路径 | HTTP 方法 | 功能描述 | 是否需要鉴权 | 关键参数 |
|---------|----------|---------|------------|---------|
| `/api/auth/register` | POST | 用户注册 | 否 | `username`, `password` |
| `/api/auth/login` | POST | 用户登录，返回 JWT | 否 | `username`, `password` |
| `/api/auth/logout` | POST | 用户登出，清除 Cookie | 是（Cookie） | 无 |
| `/api/auth/me` | GET | 获取当前登录用户信息 | 是（Cookie） | 无 |
| `/api/profile` | GET | 获取用户资料 | 是（Cookie） | 无 |
| `/api/profile` | PUT | 更新用户资料（头像/用户名/简介） | 是（Cookie） | `avatar`, `username`, `bio` |
| `/api/ai-image/generate` | POST | 调用豆包生成图片，返回图片 URL 数组 | 否（依赖后端环境变量） | `prompt` |
| `/api/bookstore/ai-detector` | POST | AI 内容检测，三级兜底策略 | 否 | `text` |
| `/api/test-proxy` | GET | 测试服务器代理连通性（开发调试） | 否 | 无 |

## 四、技术选型对比表

| 技术点 | 备选方案 | 最终选择 | 选择理由 |
|--------|---------|---------|---------|
| 前端框架 | Vue 3 / Nuxt / Remix | **Next.js 15** | App Router 支持服务端渲染与 API Route 统一管理，生态成熟，Vercel 原生支持 |
| UI 组件库 | Ant Design / MUI / Chakra UI | **shadcn/ui + Tailwind CSS** | 组件代码可直接复制修改，无样式污染，与 Tailwind 无缝集成，定制灵活 |
| AI 集成方式 | 纯后端代理 / Genkit / LangChain | **自研 UnifiedAIClient** | 支持多提供商动态切换，前端直连减少延迟，Genkit 仅保留历史兼容层 |
| 流式输出 | WebSocket / 长轮询 | **SSE（AsyncGenerator）** | LLM 服务商原生支持 SSE，实现简单，单向推送无需双向通信 |
| 数据存储（书籍内容） | localStorage / 云数据库 / SQLite | **IndexedDB** | 无需后端、大容量、支持离线，适合书籍章节等大量文本的本地存储 |
| 数据存储（用户数据） | MongoDB / PostgreSQL / Firebase | **SQLite + Prisma** | 毕设场景轻量易部署，Prisma 提供类型安全 ORM，无需单独运行数据库服务 |
| 认证方案 | Session / OAuth / Firebase Auth | **JWT + Cookie** | 无状态、易扩展，与 Next.js API Route 集成简单，无需第三方服务依赖 |
| AI 检测服务 | 单一服务 / 自训练模型 | **多级兜底（Winston AI → ZeroGPT → LLM）** | 单一服务存在下线/额度耗尽风险，多级兜底保障可用性 |
| 图像生成 | 官方 API（Stable Diffusion / DALL·E） | **豆包网页版逆向接口** | 毕设阶段无商业 API 预算，逆向接口可免费使用；后续应替换为官方 API |
| 测试框架 | Jest / Mocha | **Vitest** | 与 Vite 生态无缝集成，速度更快，TypeScript 支持更好 |
| CI/CD | Jenkins / CircleCI | **GitHub Actions + Vercel** | 与 GitHub 原生集成，免配置自动部署，Vercel 对 Next.js 零配置支持 |
