## 续写功能数据流

```mermaid
sequenceDiagram
    actor 用户
    participant Editor as Editor.tsx
    participant Hook as useAI Hook
    participant Client as UnifiedAIClient
    participant Provider as AI Provider
    participant LLM as 外部LLM服务

    用户->>Editor: 点击"续写"按钮
    Editor->>Editor: 打开 AI 写作助手 Dialog
    用户->>Editor: 填写指令，点击"生成内容"
    Editor->>Editor: 组装上下文\n(人设+角色卡+世界书+章节)
    Editor->>Hook: aiGenerateContentStream(prompt, options)
    Hook->>Client: generateContentStream(providerId, modelId, ...)
    Client->>Client: ensureProviderForCall()\n智能路由选择 Provider
    Client->>Provider: generateContentStream()
    Provider->>LLM: fetch SSE 流式请求
    loop 逐块返回
        LLM-->>Provider: chunk
        Provider-->>Client: yield chunk
        Client-->>Hook: yield chunk
        Hook-->>Editor: yield chunk
        Editor->>Editor: setContent(原文 + 分界线 + 已生成内容)
    end
    Editor->>Editor: updateChapterContent() 持久化到 IndexedDB
```

## AI 检测降级策略

```mermaid
flowchart TD
    A[用户触发 AI 检测] --> B[POST /api/bookstore/ai-detector]
    B --> C{调用 Winston AI}
    C -->|成功| D[返回检测结果\nprovider: WinstonAI]
    C -->|失败\n额度不足/网络错误| E{调用 ZeroGPT}
    E -->|成功| F[返回检测结果\nprovider: ZeroGPT]
    E -->|失败| G{调用项目内置 LLM\nautoGenerateContent}
    G -->|成功| H[返回检测结果\nprovider: LLM]
    G -->|失败| I[返回 503\n所有服务不可用]
    D --> J[前端 AiDetector 展示\nAI概率 / 人类概率进度条]
    F --> J
    H --> J
```
